Send menu to Order Bot

This bookmark copies a shop's menu — items, prices, photos, sold-out marks and (on E-Get) options — from the shop's web page (Grab, E-Get or WOWNOW) into your Order Bot, so the team can pick from it in Telegram.

Install (once, on your laptop)

  1. Show the bookmarks bar: Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac).
  2. Drag this button onto the bookmarks bar:
    📋 Send menu to Order Bot

Can't drag? Right-click the bookmarks bar → Add page…, name it Send menu to Order Bot, and paste this as the URL:

On iPhone (Safari)

  1. On this page, tap Copy below the grey box.
  2. Tap Share (the square with an arrow) → Add Bookmark → Save.
  3. Tap the Bookmarks icon (open book) → Edit → tap the bookmark you just saved.
  4. Rename it Send menu to Order Bot. Clear the address field, paste, then tap Done.

To use it: copy the shop's share link and paste it into Safari's address bar (tapping the link in Telegram would open the Grab app instead). When the menu shows, tap the address bar, type Send menu, and tap the bookmark in the list. Keep the screen on while it reads.

Use

  1. Open the shop's share link in Chrome (from Grab or E-Get → Share → Copy link). It opens the shop's web page.
  2. Click 📋 Send menu to Order Bot. Wait while it reads the menu — about 10 seconds on Grab and WOWNOW, up to a minute on E-Get (it opens each item's options).
  3. Press Send to Order Bot, enter your API token on the page that opens (first time only), then Import.

Re-run it whenever prices or promotions change. It only reads what your own browser is showing; nothing is sent until you press Import.
